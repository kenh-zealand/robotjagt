# Robotjagt

Et lille 2D skydespil udviklet af Johannes. Beskyt dig mod robotterne, og
overlev så længe som muligt.

## Sådan spiller du

Åbn `index.html` i en moderne webbrowser. Du behøver ikke installere noget.

- Bevæg dig med `WASD` eller piletasterne.
- Sigt med musen, og skyd med klik eller mellemrum.
- Hver robot giver ét point. Robotterne bliver hurtigere og dukker oftere op,
  jo flere point du får.
- Du har tre liv. Tryk `R`, når spillet er slut, for at starte forfra.
