# Robotjagt

Et top-down skydespil i browseren: overlev så mange bølger af robotter som muligt.

Hele spillet ligger i én fil, `index.html`.

Spillet virker både på computer og telefon. På telefonen går det i fuld skærm, når du trykker Start, og det spilles bedst med telefonen vendt på langs. Kan spilles på https://keha.dk/robotjagt Download den og åbn den i en browser, eller slå GitHub Pages til for repoet, så kan spillet spilles direkte fra en adresse.

## Sådan spiller du

| Handling | Computer | Mobil |
|---|---|---|
| Bevæg dig | W, A, S, D (eller piletaster) | Venstre tommel |
| Skyd (automatisk sigte) | Mellemrum | Kort tryk med højre tommel |
| Sigt selv | Mus + venstreklik | Træk med højre tommel og slip |
| Byg en væg | Højreklik (hold og træk for flere) | BYG-knappen, og tryk på banen |
| Super-missil | Q | SUPER-knappen |
| Pause | P eller Esc | Pauseknappen |
| Admin-panel (kræver kode) | E | Pauseknappen → Admin |

## Indhold

- 3000 liv og 3 skud, der lader op af sig selv
- Regenerering: 20 % liv pr. sekund efter 5 sekunder uden skade
- Buske, som robotterne ikke kan se dig i
- Byg vægge: 1 byggemateriale hvert 3. sekund. Du kan gå og skyde igennem dine egne vægge, robotterne kan ikke – de går udenom eller skyder dem i stykker
- Robotter: skyderobot, savrobot, flammerobot, teleport-robot og usynlig robot – de bliver stærkere hver bølge
- Miniboss i hver bølge og boss hver 5. bølge, med flere angreb jo længere du kommer
- ☠ Ultra-boss hver 20. bølge med meteorer, plasmakugler, flammekastere, save og missiler
- Sjældne våben at samle op (cirka hvert 2.–3. minut): shotgun, minigun, sniper, rifle og den meget sjældne flammekaster
- Super: et målsøgende missil efter hver 10. træffer
- Powerups: helbredelse, dobbelt skade, super, hurtig genladning, +500 max liv, +1 skud, +25 % skade og +25 % skudhastighed
- Highscore-tavle med top 10 (fælles for alle på keha.dk/robotjagt). Runder hvor admin-panelet er brugt, kommer ikke på
- Admin-panel med kode
- Ændringslog i spillet (klik på versionsnummeret nederst til venstre)
